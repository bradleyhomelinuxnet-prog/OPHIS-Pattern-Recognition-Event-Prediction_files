# OPHIS · Pattern-Recognition Event Prediction

**Live site: [bradleyhomelinuxnet-prog.github.io/OPHIS-Pattern-Recognition-Event-Prediction_files](https://bradleyhomelinuxnet-prog.github.io/OPHIS-Pattern-Recognition-Event-Prediction_files/)**

Working builds of the Ophis date-projection instrument and the Chronicon calendrics engine, kept as single, self-contained HTML files. Open any of them in a browser. Nothing is installed and nothing is sent anywhere.

| File | What it is |
|---|---|
| [index.html](index.html) | OPHIS · Pattern-Recognition Event Prediction, the Natorion Cipher build |
| [ophis-single.html](ophis-single.html) | The single-file build of the engine |
| [ophis-psyfy-natorion-cipher.html](ophis-psyfy-natorion-cipher.html) | Another build of the same instrument |
| [instrument-copy.html](instrument-copy.html) | Ophis Web, the date projection engine |
| [Chronicon_Engine_v2.html](Chronicon_Engine_v2.html) | The Chronicon calendrics and clocks engine |

The maintained versions live in [natori-on-psyfr](https://github.com/bradleyhomelinuxnet-prog/natori-on-psyfr) and [NatorionCipherPredictiveEngine](https://github.com/bradleyhomelinuxnet-prog/NatorionCipherPredictiveEngine). All projects: [the hub](https://bradleyhomelinuxnet-prog.github.io/).

`.oph` session files hold the dates you enter, so `.gitignore` keeps them out of the repository.
